# AI Requirements Reviewer

ИИ-агент для статической проверки документов с требованиями: находит
двусмысленные, неполные, противоречивые и непроверяемые формулировки и
формирует отчёт на русском языке.

Проект для **BCC-HUB x MNU FinTech Hackathon**.

## Текущий статус

Реализован **первый этап — фундамент проекта**:

- загрузка документов (Markdown и PDF, с сохранением номеров страниц для PDF);
- модели данных (`SourceDocument`, `Requirement`, `RequirementCollection`);
- черновая нарезка требований (эвристика-заполнитель, без LLM);
- CLI-команда `analyze` со статистикой обработки и предварительным отчётом.

ИИ-анализ формулировок (LLM, оценка качества, поиск противоречий, итоговый
отчёт) будет добавлен на следующих этапах. Текущий отчёт — заготовка:
реальная проверка требований **не выполняется** и честно помечена в файле.

## Установка

Требуется Python 3.11+.

```bash
python3 -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
```

## Запуск

```bash
python -m app.main analyze --input documents_organization/requirements.md --output reports/report.md
```

- `--input` — путь к документу требований (`.md`, `.markdown` или `.pdf`);
- `--output` — путь к файлу отчёта (каталог создаётся автоматически).

После запуска в консоль выводится статистика (формат, объём, число
кандидатов в требования), а отчёт записывается в `reports/report.md`.

## Ключ LLM

На текущем этапе ключ не нужен. Когда ИИ-анализ будет подключён:

1. Получите бесплатный API-ключ, например в Google AI Studio:
   <https://aistudio.google.com/>.
2. Скопируйте `.env.example` в `.env`.
3. Впишите ключ в `LLM_API_KEY`, при необходимости укажите модель в `LLM_MODEL`.

`.env` добавлен в `.gitignore`, секреты в репозиторий не попадают.

## Структура проекта

```text
app/                      код агента
├── main.py               точка входа: python -m app.main
├── cli.py                CLI-команды (Typer) и предварительный отчёт
├── config.py             настройки из переменных окружения / .env
├── models/               Pydantic-модели данных
│   └── requirement.py    SourceDocument, Requirement, RequirementCollection
├── ingestion/            загрузка документов
│   └── document_loader.py  PDF (PyMuPDF) и Markdown
└── services/             бизнес-логика поверх документов
    └── requirement_extractor.py  нарезка требований (пока эвристика)
tests/                    unit-тесты
reports/                  сгенерированные отчёты
```
